# getburncraft.github.io

The website for [BurnCraft](https://github.com/amruthwo/BurnCraft), a free, open-source laser design and control app.
Live at <https://getburncraft.github.io/>.

- `template.html` is the page's source. Run `python3 build.py` to make `index.html` (it puts the ant mark's
  outline from `img/ant-mark.svg` into the animated hero).
- `img/` holds screenshots taken with BurnCraft's own `--screenshot` mode, and "burned wood" versions of the
  Burn Colony tiles.
- The page is self-contained: no trackers, no fonts or scripts from other sites.

Free software under the GNU GPL v3 or later, like BurnCraft. BurnCraft isn't affiliated with LightBurn Software,
ArtCraft or Craft Anything.
